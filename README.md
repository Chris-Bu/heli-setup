# Heli Setup – Digitale Rotorkopfvermessung

Herstellerunabhängiges Tool zur digitalen Vermessung und Einstellung des Rotorkopfs von RC-Modellhubschraubern unter Verwendung des digitalen Winkelmessers von Soko-Heli-Tools.

Die Anwendung ermöglicht unter anderem die Kalibrierung einer virtuellen Rotorwelle (Virtual Main Shaft), um Messungen auch bei schräg stehender Rotorwelle durchzuführen.

Als offlinefähige Web-App (PWA) für Windows und Android konzipiert.

**Entwicklungsstand:** Die automatische Berechnung aller Pitch-Sollwerte ist noch nicht vollständig implementiert.
